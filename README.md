

\# Campus Bites



Campus Bites is a simple campus cafeteria website developed using HTML and CSS as part of the DevOps Fundamentals assignment.



Project Pages:



\- Home Page

\- Menu Page

\- Deals Page

\- Order Page

\- Feedback Page



Technologies Used:



\- HTML5

\- CSS3

\- Git

\- GitHub



Project Structure:



campus-cafeteria/

├── src/

│   ├── index.html

│   ├── menu.html

│   ├── deals.html

│   ├── order.html

│   └── feedback.html

├── styles/

│   └── style.css

├── README.md

└── .gitignore





Team Collaboration:



This project uses Git and GitHub for version control, feature branches, pull requests, code reviews, and release management.



Shared Stylesheet:



All five HTML pages use one shared stylesheet located at "styles/style.css".
